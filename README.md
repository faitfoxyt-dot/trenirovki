# trenirovki

Трекер тренировок на двоих: атлет отмечает подходы, админ проверяет их по видео из Telegram.
Статический сайт (HTML + CSS + JS-модули, без сборки) на GitHub Pages и Supabase.

- **Демо без базы и входа:** `index.html?demo=1`. Данные в памяти, переключатель ролей сверху.
- **Локально:** `python3 -m http.server` в корне и открыть `http://localhost:8000/?demo=1`.

## Устройство

| Путь | Что там |
| --- | --- |
| `index.html`, `manifest.webmanifest`, `icons/` | Оболочка и установка на iPhone («На экран Домой») |
| `css/app.css`, `fonts/` | Тёмная тема, шрифты Unbounded и Onest (лежат в репозитории) |
| `js/app.js` | Режим (демо / Supabase), вход, вкладки, переходы |
| `js/views/` | Экраны: вход, Сегодня, Календарь, Проверка, План |
| `js/logic.js`, `js/util.js` | Правила дня и даты — общие для обоих режимов |
| `js/api/supabase.js`, `js/api/demo.js` | Одинаковый набор функций: настоящая база и память вкладки |
| `js/config.js` | Project URL и publishable key — публичные по задумке |
| `vendor/supabase.js` | Готовый ESM-бандл `@supabase/supabase-js` 2.117.3 (esbuild) |
| `supabase/migrations/` | Схема базы, права (RLS) и серверные функции |
| `supabase/make-admin.sql` | Выдать роль админа своей почте |

## Правила, которые держит база

- «Сегодня» — по зоне `Europe/Tallinn`, время ставит сервер. День закрывается в 00:00, до 03:00 можно отметить только видео.
- Атлет не пишет в таблицы напрямую: только через `log_set` и `save_morning`. Проверка (`review_set`) и план — только админ.
- Секретных ключей в репозитории нет и не будет.
